Provenance, interpretation and update status
Uniform evaluation histories are shared across configurations; the mixed-mode probe-training histories still differ. Decoder comparisons are descriptive, not proof of policy use, causal performance benefit, unseen-ship inference, or a seed-general hyperparameter ranking.
Only completed native measurement JSONs are read from W&B. No new probes, checkpoint loads, training changes or W&B writes occur. Checkpoint files are compact gzip JSON, fetched only for the selected trial. A JSON artifact can arrive before/after its history row; pending uploads remain unavailable.
Missing tracebacks are not inferred: a failed W&B state identifies a failed run, not its root cause. The published step marker can precede completion of its memory report. Final Bayesian objectives are shown only for finished runs, never substituted with early return.
